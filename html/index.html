Instruções de Uso

O primeiro passo é configurar onde seus bancos de questões serão armazenados.

  1. No Google Drive, crie uma pasta nova para o QuestGen IA.
  2. Clique com o botão direito na pasta, selecione "Compartilhar" e depois "Copiar link". O ID da pasta é a longa sequência de caracteres no final do link.
  3. Na aplicação, clique em Configurações, cole o ID no campo Pasta Raiz e clique em "Salvar Pasta".
  4. Após salvar, você poderá criar seu primeiro banco de questões nomeando-o (ex: "Direito Administrativo 2025") e clicando em "Criar".

Com um banco de questões ativo, você pode gerar conteúdo com a IA.

  • Navegue até Gerar Questões no menu.
  • Nome da Disciplina: Insira o nome da matéria (ex: "Licitações"). Isso ajuda a organizar seu banco.
  • ID do Documento Google: Forneça o ID de um Google Docs que servirá como material base para a IA.
  • Número de Questões: Escolha quantas questões deseja gerar (1 a 10).
  • Clique em Iniciar Geração e aguarde.

  • Banco de Questões: Abre um resumo das suas questões. Clique em uma disciplina para ver, editar ou excluir questões individuais.
  • Exportar: Exporte as questões nos formatos Moodle GIFT, Moodle XML ou para um Google Docs.
  • Limpar Dados: Cuidado! Esta opção apaga TODAS as questões do banco de dados ativo.
Sobre o QuestGen IA

QuestGen IA é uma ferramenta para auxiliar na criação de questões de múltipla escolha utilizando o poder da Inteligência Artificial do Google Gemini.

Este projeto foi idealizado, projetado e desenvolvido por Vitor Krewer utilizando Inteligência Artificial e Google Apps Script, demonstrando a flexibilidade e capacidade da plataforma para desenvolvimento de aplicações web integradas aos serviços Google.
